# OrangeHRM Manual Testing Project

A complete Manual Testing project for the OrangeHRM Demo Application using industry-standard QA documentation.

## 📌 Project Overview

This repository contains a complete **Manual Testing Project** performed on the **OrangeHRM Demo Application**.

The project includes industry-standard QA documentation such as:

- Test Plan
- Test Scenarios
- Test Cases
- Requirement Traceability Matrix (RTM)
- Bug Report
- Test Summary Report

---

## 🎯 Objectives

The objective of this project is to validate the functionality of the OrangeHRM Login module through manual testing.

Testing includes:

- Login Validation
- Logout Functionality
- Forgot Password
- Field Validation
- Password Masking
- UI Verification
